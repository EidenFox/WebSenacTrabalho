Este é um projeto web desenvolvido para um trabalho acadêmico, focado na listagem e recomendação de animes favoritos. A interface foi construída utilizando técnicas de CSS, como **Glassmorphism**, garantindo uma estética inspirada em transparência.

## 🌐 Demonstração Online

O projeto está hospedado e pode ser visualizado através do link:

👉 **[anime.eidenfox.xyz](https://anime.eidenfox.xyz/)**

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica dos elementos e metadados Open Graph.
* **CSS3:** Estilização completa, com foco em:
* **Glassmorphism:** Uso intensivo de `backdrop-filter` e cores RGBA.
* **Flexbox:** Para garantir um layout dinâmico e responsivo.
* **Visual Effects:** Sombras projetadas (`box-shadow`), efeitos de hover e sobreposição de filtros no background.



## 📋 Funcionalidades

* **Listagem Dinâmica:** Seções dedicadas a animes como *Frieren*, *Death Note* e *Fullmetal Alchemist*.
* **Interface Imersiva:** Background fixo com efeito de desfoque via pseudo-elemento `::before`.

## 🛠️ Como Executar o Projeto

1. Clone o repositório.
2. Certifique-se de que a estrutura de pastas contém o arquivo `style.css` e o diretório `img/`.
3. Abra o arquivo `index.html` em qualquer navegador (Chrome, Firefox, Brave, etc.).

This is a web project developed for an academic assignment, focusing on listing and recommending favorite animes. The interface was built using CSS techniques like **Glassmorphism**, ensuring an aesthetic inspired by transparency.

## 🌐 Online Demo

The project is hosted and can be viewed at:

👉 **[anime.eidenfox.xyz](https://anime.eidenfox.xyz/)**

---

## 🚀 Technologies Used

* **HTML5:** Semantic structuring of elements and Open Graph metadata.
* **CSS3:** Complete styling, focusing on:
* **Glassmorphism:** Heavy use of `backdrop-filter` and RGBA colors.
* **Flexbox:** To ensure a dynamic and responsive layout.
* **Visual Effects:** Box shadows (`box-shadow`), hover effects, and background filter overlays.



## 📋 Features

* **Dynamic Listing:** Sections dedicated to animes such as *Frieren*, *Death Note*, and *Fullmetal Alchemist*.
* **Immersive Interface:** Fixed background with a blur effect using the `::before` pseudo-element.

## 🛠️ How to Run the Project

1. Clone the repository.
2. Ensure the folder structure contains the `style.css` file and the `img/` directory.
3. Open the `index.html` file in any browser (Chrome, Firefox, Brave, etc.).
